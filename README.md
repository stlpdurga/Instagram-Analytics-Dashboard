# Instagram-Analytics-Dashboard
📸 Excited to share my latest Power BI project: Instagram Analytics Dashboard 🚀

This dashboard provides insights into content performance, audience growth, reach, impressions, and engagement metrics to support data-driven social media strategies.

🔹 Key Highlights:
✅ 188M+ Total Reach
✅ 254M+ Total Impressions
✅ 15M+ Followers Gained
✅ 11M+ Total Engagement
✅ Engagement Rate Analysis
✅ Content Category Performance
✅ Media Type Comparison
✅ Top Performing Posts Analysis
✅ Audience Growth Tracking
✅ Best Time to Post Insights

🛠️ Tools Used:
• Power BI
• DAX
• Power Query
• Google Colab (Python)
• Data Cleaning & Transformation

📊 Key Insights:
📌 Image posts generated the highest engagement.
📌 Fashion, Photography, Fitness, and Food content performed best.
📌 Audience growth accelerated significantly in 2025.
📌 Strong positive relationship between reach and engagement.
